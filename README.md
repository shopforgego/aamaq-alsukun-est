## ⚙️ التعديل وتحديث بيانات المنشأة عبر متغيرات البيئة (`.env`)

تم بناء هذا المشروع بهيكلية متكاملة تقرأ جميع بيانات التواصل والاعتماد التجاري والأسعار والشحن مباشرة من ملف `.env` دون الحاجة إلى تعديل الكود البرمجي:

```env
VITE_STORE_NAME_AR="متجر أعماق السكون للقهوة والمنزل"
VITE_COMPANY_NAME_AR="مؤسسة أعماق السكون"
VITE_COMMERCIAL_REGISTRATION="7055092204"
VITE_TAX_NUMBER="310550922040003"
VITE_NATIONAL_ADDRESS_SHORT="JHEA2569"
VITE_CITY="جدة"
VITE_CONTACT_PHONE="0559946358"
VITE_CONTACT_WHATSAPP="966559946358"
VITE_CONTACT_EMAIL="aamaqalsukun@gmail.com"
```
